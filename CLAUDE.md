# Easy Rental

## Stack
React + Express + Supabase + Vercel

## Deploy
Always use `bash scripts/deploy.sh [public|admin|all]` — never raw `vercel` commands.
- Public: deploy from repo root (project "easy-rental" → easy-rental.ca)
- Admin: deploy from `admin-dashboard/` (project "easy-rental-admin" → admin.easy-rental.ca)
