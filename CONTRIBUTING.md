# Easy Rental - Contributing Guidelines

Thank you for your interest in contributing to Easy Rental!

## Getting Started

1. Clone the repository
2. Install dependencies for both backend and frontend
3. Set up your environment variables from `.env.example` files
4. Start the development servers

## Development Standards

- Use ES6+ syntax
- Follow the existing code structure
- Write meaningful commit messages
- Test your changes before submitting

## Code Style

### Backend
- Use camelCase for variables and functions
- Use PascalCase for class names
- Use consistent indentation (2 spaces)
- Follow Promises/async-await patterns

### Frontend
- Use functional components with React hooks
- Use meaningful component names
- Follow component structure conventions
- Keep components focused and reusable

## Submitting Changes

1. Create a new branch for your feature/fix
2. Make your changes
3. Test thoroughly
4. Submit a pull request with a clear description

## Questions?

Feel free to reach out if you have any questions or need clarification.

Happy coding!
